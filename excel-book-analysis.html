Project Overview

I used an Amazon bestselling books dataset containing 550 original records and added 50 simulated records with intentional data quality issues for practice. I cleaned and validated the data in Excel, removed exact duplicates, standardized text and prices, and kept questionable zero-price values flagged for review. The finished dataset supports simple lookup, PivotTable, and dashboard exercises.

The additional 50 records and their quality issues were simulated for learning purposes; they are not additional real Amazon bestseller observations.

Project Overview

I used Python to explore the Sample Superstore dataset, inspect and prepare the data, calculate business metrics, and visualize sales performance by category, region, and month.

Dataset

Sample Superstore contains 9,994 rows and 21 columns covering orders, products, customers, sales, discounts, and profit from 2014 through 2017. This is the same dataset used in my Power BI project.

12. Monthly Sales Trend Analyze monthly sales over time. ⌄
Python Code 
# Calculate monthly sales
monthly_sales = df.groupby(
    df["Order Date"].dt.to_period("M")
)["Sales"].sum()

# Create monthly sales trend chart
monthly_sales.index = monthly_sales.index.to_timestamp()
monthly_sales.plot(kind="line", marker="o", figsize=(12, 5))

# Add chart labels
plt.title("Monthly Sales Trend")
plt.xlabel("Month")
plt.ylabel("Total Sales ($)")

# Improve layout
plt.grid(True)
plt.tight_layout()

# Display chart
plt.show()

Actual Output

Key Findings

  • Technology generated the highest sales ($836,154.03) and profit ($145,454.95).
  • Furniture generated $741,999.80 in sales but only $18,451.27 in profit.
  • The West region led in both sales ($725,457.82) and profit ($108,418.45).
  • Monthly sales fluctuated, with a strong peak toward the end of 2017.
